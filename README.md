# 한옥이와 떠나는 서창 역사 여행

서창한옥문화관 길잡이 **한옥이**와 함께 서창의 네 어른(눌재 박상 · 회재 박광옥 · 삽봉 김세근 · 야은 김용훈)을 만나는 인터랙티브 웹북 시제품입니다.

- 한 파일(`index.html`)로 동작하는 정적 페이지예요. 이미지는 파일 안에 들어 있어요.
- GitHub Pages(`main` 브랜치, 루트)로 배포합니다.
- 현장 QR 주소: `…/#qr-sang`, `#qr-gwangok`, `#qr-segeun`, `#qr-yonghun`
- 인물 정보는 공개 자료 기준 초안이며 감수 전입니다. 페이지 안의 점선 '감수 메모'를 확인해 주세요.
